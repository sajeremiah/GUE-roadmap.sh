# CLI Github User Events checker

## Project task: https://roadmap.sh/projects/github-user-activity

### How to run

#### Clone the repository and run the following command:

```
git clone https://github.com/sajeremiah/GUE-roadmap.sh
cd ./GUE-roadmap.sh
```

#### Run the following command to build and run the project:

```sh
make build                          > build in ./bin
make run <ARGUMENTS>                > build & run with args in cmd line
./bin/github-activity USERNAME      > run program
```

## Example
```sh
./bin/github-activity sajeremiah 
```
